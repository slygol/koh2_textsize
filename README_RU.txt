KOH2 LARGER TEXT — ПРЕДЗАГРУЗОЧНЫЙ ПАТЧЕР BepInEx
=================================================

Назначение
----------
Патчер увеличивает обычные Unity/TextMeshPro-надписи, размер которых невозможно
изменить через .def-файлы игры.

Он запускается до загрузки Assembly-CSharp и добавляет масштабирование прямо в
игровой метод UIText.OnEnable. Изменение происходит только в памяти процесса:
оригинальный Assembly-CSharp.dll на диске не перезаписывается.

ВАЖНО: обычный мод "Larger Text (125%)" в меню игры нужно отключить, иначе
часть HyperText будет увеличена дважды.


Готовый пакет
-------------
После сборки всё необходимое для установки находится в папке:

    package

Содержимое package нужно копировать в корневую папку игры — туда, где лежит
Sovereign.exe. Сама папка package при этом не копируется: копируются файлы и
папки внутри неё.

После копирования должно получиться примерно так:

    Sovereign.exe
    winhttp.dll
    doorstop_config.ini
    BepInEx\core\...
    BepInEx\patchers\KoH2.LargerText.Patcher.dll


Первый запуск
-------------
1. Удалите старый экспериментальный файл, если он установлен:

       BepInEx\plugins\KoH2.LargerText.Plugin.dll

2. Отключите обычный мод "Larger Text (125%)" в меню игры.
3. Запустите игру обычным способом.
4. Откройте несколько сообщений, подтверждений и других всплывающих окон.

В журнале BepInEx должны появиться строки о загрузке patcher method и патчинге
Assembly-CSharp.


Масштаб
-------
Текущая версия собрана с коэффициентом 1.25. Он задаётся константой TextScale
в PreloaderPatcher.cs; после изменения нужно заново выполнить build_plugin.ps1.


Удаление
--------
Удалите только:

    BepInEx\patchers\KoH2.LargerText.Patcher.dll

Сам обычный LargerText-мод продолжит работать.


Сборка из исходников
--------------------
Откройте PowerShell в папке LargerTextPlugin и выполните:

    .\build_plugin.ps1

DLL автоматически попадёт в:

    package\BepInEx\patchers\KoH2.LargerText.Patcher.dll


Ограничения
-----------
У некоторых элементов интерфейса фиксированный размер контейнера. Слишком
большой Scale может привести к переносу или обрезанию надписей. Начинать лучше
с 1.20–1.25.

BepInEx является сторонним загрузчиком. Для сетевой игры лучше использовать
одинаковый набор файлов у всех участников либо временно удалить DLL плагина.
